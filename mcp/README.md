# Carbonfly MCP — server package

> This is the MCP server sub-package. For the full documentation, see [../README.md](../README.md).

## Install from here

```powershell
cd mcp
pip install fastmcp numpy
```

## Start the server

```powershell
cd src
python -m carbonfly_mcp.server
```
