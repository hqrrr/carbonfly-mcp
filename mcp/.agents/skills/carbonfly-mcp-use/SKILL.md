## When to use this skill

Use this skill when the user wants to:

1. Set up and run indoor CO2 CFD simulations using OpenFOAM through WSL
2. Create simulation geometry without CAD software (box, cylinder, sphere primitives, or import STL)
3. Configure ventilation boundaries (inlets, outlets, walls, dynamic respiration, recirculation)
4. Generate OpenFOAM cases and run meshing (blockMesh + snappyHexMesh)
5. Run transient or steady-state CO2 dispersion simulations
6. Post-process results and assess Indoor Air Quality (IAQ)

**Trigger keywords**: `carbonfly`, `cbf`

## Prerequisites

Before running simulations, the user **must** have:

- **WSL 2** with a Linux distribution (e.g., Ubuntu 20.04/22.04)
- **OpenFOAM v10** installed in WSL
- **Python 3.10+** on the Windows host

Carbonfly MCP does NOT require Rhino, Grasshopper, or any CAD software.

Always run `check_environment` first to verify WSL and OpenFOAM are available.

## Workflow overview

### Phase 1: Workspace Setup

```
check_environment()
create_workshop(root=".", name="my_simulation")
```

### Phase 2: Geometry

Create geometry using primitives or import STL files:

```
create_box_stl(workshop_root, stl_name="room", dimensions=(5, 4, 3))
create_cylinder_stl(workshop_root, stl_name="inlet_01", radius=0.15, height=0.3, origin=(0.5, 2.0, 2.8))
create_sphere_stl(workshop_root, stl_name="person_head", radius=0.12, origin=(2.5, 2.0, 1.1))
import_stl(workshop_root, source_path="C:/path/to/geometry.stl", stl_name="custom_wall")
```

Geometry is in **meters**. Use `list_geometry` to verify.

### Phase 3: Boundary Conditions

```
configure_inlet(workshop_root, stl_name="inlet_01", velocity=(0, 0, 1.5), temperature=293.15, co2_fraction=0.0004)
configure_outlet(workshop_root, stl_name="outlet_01")
configure_wall(workshop_root, stl_name="room")
configure_dynamic_respiration(workshop_root, stl_name="person_head", freq=12, minute_vent_L_min=7.2)
configure_recirculation(workshop_root, supply_stl="supply_01", return_stl="return_01")
```

Use `list_boundaries` to verify. Use `clear_boundaries` to reset.

### Phase 4: Case Generation

```
generate_case(workshop_root, case_name="case01", cell_size_m=0.25, padding_m=1.0, end_time=120.0, delta_t=0.01)
```

Key parameters:
- `cell_size_m`: target mesh cell size (smaller = finer mesh, longer runtime)
- `padding_m`: extra space around geometry for background mesh
- `simulation_type`: "transient" or "steady"
- `end_time`: simulation duration in seconds
- `delta_t`: time step size

### Phase 5: Meshing and Simulation

```
run_meshing(workshop_root, case_name="case01")
run_simulation(workshop_root, case_name="case01", timeout=3600)
```

Check status anytime:
```
get_simulation_status(workshop_root, case_name="case01")
```

### Phase 6: Post-Processing

```
list_results(workshop_root, case_name="case01")
read_co2_field(workshop_root, case_name="case01")
read_temperature_field(workshop_root, case_name="case01")
assess_iaq(workshop_root, case_name="case01", standard="EN", co2_outdoor=400)
probe_point(workshop_root, case_name="case01", point=(2.5, 2.0, 1.5), field="CO2")
```

Supported IAQ standards: EN, LEHB, SS, HK, UBA, DOSH, NBR

## Workshop directory layout

Every workshop directory has this structure. **Always tell the user the absolute path** when results are asked.

```
<workshop_root>/
├── workshop.json              # metadata
├── boundaries.json            # boundary conditions
├── stl/                       # geometry files (ASCII STL)
│   ├── room.stl               #   generated by create_box_stl
│   ├── inlet.stl              #   generated by create_cylinder_stl
│   └── ...                    #   manual files placed here before import_stl
└── cases/<case_name>/         # OpenFOAM case
    ├── <case_name>.foam       # ← ParaView marker (open this to view 3D results)
    ├── 0/                     # initial fields (U, T, CO2, p, ...)
    ├── constant/triSurface/   # working STL copies
    ├── system/                # blockMeshDict, controlDict, etc.
    └── <time>/                # result snapshots (e.g., 10/, 60/, 120/)
        ├── U                  # velocity at this time
        ├── T                  # temperature at this time
        └── CO2                # CO2 at this time
```

## File location guidance for users

When the user asks where files are, explain:

- **Manual STL placement**: Put `.stl` files into `<workshop_root>/stl/`, then call `import_stl` to register them. Or use `import_stl` with any external path to auto-copy.
- **Generated cases**: Found at `<workshop_root>/cases/<case_name>/`. All files are plain text, inspectable with any editor.
- **Simulation results**: Numbered directories inside the case (e.g., `10/`, `60/`). Use `list_results` to see what's available.
- **3D visualization**: User needs **ParaView** (separate installation from [paraview.org](https://www.paraview.org)). Open the `<case_name>.foam` file in ParaView, click Apply, select fields (CO2, U, T) from the dropdown.
- **Programmatic result reading**: Use `read_co2_field`, `read_temperature_field`, `probe_point`, `assess_iaq` — no ParaView needed.

## Important notes

1. **Always call tools in order**: workspace -> geometry -> boundary -> case -> mesh -> simulate -> post-process
2. **Always run `check_environment` first** before any simulation work.
3. **Coordinate system**: X/Y/Z in meters, Z is up (vertical)
4. **CO2 values**: Use mass fraction in boundary configuration (0.0004 ≈ 400 ppm). When displaying to users, show ppm (mass_fraction × 28.96/44.01 × 10⁶).
5. **Temperature**: Always in Kelvin (293.15 K = 20 °C). When displaying to users, show both K and °C.
6. **STL format**: All geometry is ASCII STL. Binary STL import is not supported.
7. **WSL timeout**: Long simulations may need extended timeouts. Use `timeout` parameter.
8. **Workshop isolation**: Each simulation should have its own workshop to avoid geometry conflicts.
9. **After `run_meshing` or `run_simulation`**: Tell the user the case path so they can find results. Remind them ParaView is available for 3D viewing.
10. **Results go into time directories**: the final time step usually has the most interesting data for IAQ assessment.

## Typical values

| Parameter | Typical Value | Notes |
|---|---|---|
| Room size | 5×4×3 m | Small office/classroom |
| Inlet velocity | 0.5–2.0 m/s | Mechanical ventilation |
| Inlet temperature | 291–295 K | Supply air |
| Outdoor CO2 | 400 ppm | Clean outdoor air |
| Exhaled CO2 | 40,000 ppm (mass fraction 0.04) | Human respiration |
| Cell size | 0.15–0.50 m | Trade-off: speed vs accuracy |
| Time step (transient) | 0.01 s | For Co < 1 |
| Simulation duration | 60–600 s | Depends on ventilation rate |
| Breathing rate | 12 bpm | Resting adult |
| Minute ventilation | 7.2 L/min | Resting adult |

## Troubleshooting

- **WSL not found**: Install WSL 2 and a Linux distribution
- **OpenFOAM not found**: Install OpenFOAM v10 in WSL (`/opt/openfoam10/etc/bashrc`)
- **snappyHexMesh fails**: Check geometry (watertight? self-intersecting?), try larger cell_size_m
- **Solver divergence**: Reduce delta_t, increase mesh quality, check boundary conditions
- **File not found errors**: Always run `check_environment` first, verify case exists with `list_workshops`
